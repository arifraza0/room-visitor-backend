# Room Visitor Management System

A web-based visitor management system for recording and managing room visitors.

## Features

- Visitor entry form
- Admin login
- Admin dashboard
- Search visitors
- View visitor details
- Mark visitor exit
- Delete visitor records
- MongoDB database

## Technology Used

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- CSS

## Project Purpose

This project helps manage visitor entries digitally and allows the administrator to view and manage visitor records.
